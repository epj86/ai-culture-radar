# Data directory

This directory will contain publicly shareable, non-sensitive research inputs and outputs.

Do not commit API keys, private company materials, personal identifying information, confidential transcripts, or licensed datasets without permission.

Planned datasets for Study 001:

- `prompts.csv`: `prompt_id,category,prompt,reference_interpretation,acceptable_alternatives,notes`
- `responses.csv`: `prompt_id,model_provider,model_id,test_date,run_id,response,settings_notes`
- `scores.csv`: `prompt_id,run_id,reviewer_code,interpretation,calibration,assumptions,usefulness,rationale`

Schemas are provisional until the study protocol is finalized. No empirical dataset exists yet.
